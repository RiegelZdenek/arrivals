# Background Location Access and 15-Minute Underground Fallback

To allow the home screen widget to detect the user's current stop while walking around without opening the Settings activity, the app requests `ACCESS_BACKGROUND_LOCATION` ("Allow all the time") and `FOREGROUND_SERVICE_LOCATION`, resolving coordinates across high-accuracy GPS, balanced network triangulation (`PRIORITY_BALANCED_POWER_ACCURACY`), and `lastLocation`. When satellite and network locks fail (such as inside deep metro stops), we accept cached Location Fixes up to 15 minutes old, and fall back to querying live departures for the currently active Stop by name if no valid Location Fix is available.
