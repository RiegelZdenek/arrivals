# Production Release Pipeline Architecture, Versioning Scheme, and Keystore Signing

To establish a repeatable, auditable distribution pipeline for production releases alongside fast pull-request CI and nightly pre-releases, we introduce an automated production release workflow (`.github/workflows/release.yml`) triggered on SemVer tag pushes (`v*.*.*`) and on-demand via `workflow_dispatch`. Prior to artifact compilation, the workflow executes the test suite (`testDebugUnitTest`) as an unconditional quality gate to prevent shipping broken binaries. Release versioning decouples git tags from hardcoded build configuration by injecting dynamic Gradle properties (`-PappVersionName` and `-PappVersionCode`): the human-readable `VERSION_NAME` is normalized from the tag (`MAJOR.MINOR.PATCH`), while the integer `VERSION_CODE` is calculated via the monotonic formula `(MAJOR * 10000) + (MINOR * 100) + PATCH`, guaranteeing strict monotonically increasing version codes across major, minor, and patch releases while accommodating up to 99 minor and 99 patch revisions per major release without collision. The pipeline packages both a standalone universal release APK (`assembleRelease`) for direct sideloading and an Android App Bundle (`bundleRelease`) for Play Store distribution. To maintain security hygiene while facilitating testing and forks, cryptographic package signing employs a two-tier strategy: if repository secrets (`RELEASE_KEYSTORE_BASE64`, `RELEASE_KEYSTORE_PASSWORD`, `RELEASE_KEY_ALIAS`, `RELEASE_KEY_PASSWORD`) are configured, the pipeline decodes the production keystore on an ephemeral path, whereas when credentials are absent, the Gradle build configuration gracefully falls back to inheriting the Android debug signing configuration via `initWith(getByName("debug"))`. Finally, the workflow parses version-specific changelog entries from `CHANGELOG.md` (falling back to generated release metadata if omitted), publishes a formal GitHub Release with both packages attached, and retains build artifacts in GitHub Actions storage for 30 days.
