# Screen-Unlock Proximity Refresh and Out-of-Range Cache Invalidation

To guarantee that the departure board widget reflects the commuter's immediate surroundings when glancing at their phone without relying on battery-throttled periodic background workers, the widget triggers a fresh Location Fix on every device unlock (`ACTION_USER_PRESENT`) and on display wakeups (`ACTION_SCREEN_ON`, rate-limited to once every 3 minutes). If the user has moved more than 50 meters from their last known Location Fix, the app fetches nearby Stops within the user's configured Search Radius (default 300m); if stationary (<= 50m), it refreshes live Departures for the currently active Stop (cooldown: 15 seconds). If a fresh Location Fix indicates that previously Cached Departures are farther than the configured Search Radius and no Stops are found within range, the cache is purged and the widget transitions to an Empty state rather than displaying an expired, distant stop across town. Walking distances of 1,000 meters or greater are formatted in kilometers (`X.X km`).
